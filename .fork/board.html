The observability target, reframed. The harness's own session file is the record: for run 2 it held the full input for all 59 calls where Warp's log truncated 14, and the two joined on the tool-call id Warp already writes. Warp adds only what no harness file has: what it decided, which surface answered, why a request was refused, and live state. The viewer merges the two on that id, orders by time, labels every line by author, and never writes. Compaction is a boundary row, so a session can always be viewed without being compacted, which was I21's whole ask.
